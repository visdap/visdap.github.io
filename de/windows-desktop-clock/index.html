Visdap › Desktop-Uhr für Windows

Windows

Eine 24-Stunden-Uhr auf Ihrem Windows-Desktop

Visdap hält Ihren ganzen Tag auf einem runden 24-Stunden-Zifferblatt in der Bildschirmecke. Sie sehen, wie viel von einem Arbeitsblock übrig ist, ohne das Fenster zu wechseln.

  • Kein Konto
  • Keine Werbung, kein Tracking
  • Funktioniert offline

Was Sie unter Windows bekommen

  • Immer im Blick

    Das Zifferblatt kann über anderen Fenstern bleiben. Im Geistmodus gehen Klicks durch es hindurch zum Fenster darunter.

  • Ihre Größe und Transparenz

    Jede Größe von 150 bis 900 Pixel, mit einstellbarer Transparenz.

  • Schnell erfassen

    Drücken Sie Strg+Umschalt+Leertaste, um aus jeder App eine Aufgabe hinzuzufügen.

  • Erinnerungen, Pomodoro und Projekte

    Erinnerungen mit Ton, ein Pomodoro-Timer und Projekte mit Deadline-Streifen. Pomodoro und Projekte gibt es mit Pro.

Fragen und Antworten

Welche Windows-Versionen werden unterstützt?

Windows 10 (Version 1809 oder neuer) und Windows 11.

Kann es mit Windows starten?

Ja. Den Autostart können Sie in den Einstellungen einschalten.

Braucht es Internet?

Nein. Nur der Kauf oder die Wiederherstellung von Pro braucht eine Verbindung zum Microsoft Store.
